The Vine developer API lets your server create payment links, hosted checkout sessions, invoices and bill payments. Use it when you want Vine to handle collection while your product controls the customer experience.

## Base URL

| Environment | Base URL | Key |
| --- | --- | --- |
| Sandbox | `https://sandbox.vine.ng` | `sk_test_...` |
| Production | `https://api.vine.ng` | `sk_live_...` |

Use the [sandbox](/developers/sandbox) while building. All requests and responses use JSON, and amounts are in kobo.

## Authentication

Create an API key in **Dashboard → Developers**, then send it as a bearer token:

```http
Authorization: Bearer sk_test_your_key
```

<Warning>
  API keys are secrets. Keep them on your server. Never put a key in browser code or a mobile app.
</Warning>

Keys are mode-bound:

| Key prefix | Mode | Use for |
| --- | --- | --- |
| `sk_test_...` | Test | Building and testing |
| `sk_live_...` | Live | Real customer payments |

## Scopes

Each key only unlocks the scopes selected when it was created.

| Scope | What it unlocks |
| --- | --- |
| `PAYMENTS` | Payment links, invoices, digital products and courses |
| `BILLS` | Bill categories, validation and payments |
| `CHECKOUT` | Hosted checkout sessions |

Missing a scope returns `403 INSUFFICIENT_SCOPE`.

## Amounts

All monetary fields are integers in kobo:

- `100` = ₦1
- `500000` = ₦5,000
