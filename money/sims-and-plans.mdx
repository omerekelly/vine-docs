## Plans

SIM plans are workspace subscriptions that control how many SIMs a business can link and manage. The monthly fee is charged from the workspace deposit balance.

Choose or change a plan in the dashboard under **SIM plans** at [console.vine.ng/subscriptions](https://console.vine.ng/subscriptions). Plan changes take effect immediately after a successful charge.

Each business workspace has its own plan and its own linked SIMs.

## List available plans

`GET /v1/plans` is public and returns the current plan catalogue.

```bash
curl https://api.vine.ng/v1/plans
```

```json
{
  "plans": [
    {
      "slug": "starter",
      "name": "Starter",
      "priceMonthlyKobo": 250000,
      "simLimit": 1,
      "apiRateLimit": 60
    }
  ]
}
```

## SIM API

SIM endpoints require an API key with the `SIMS` scope and an active SIM plan. API keys are created in **Dashboard → Developers**.

| Method | Endpoint | Description |
| - | - | - |
| GET | `/v1/sims/carriers` | List supported carriers (public) |
| GET | `/v1/sims` | List linked SIMs |
| POST | `/v1/sims/link` | Start linking a SIM; sends an OTP |
| GET | `/v1/sims/link/:authStateId` | Check the linking session |
| POST | `/v1/sims/link/:authStateId/advance` | Submit the OTP, passcode or PIN |
| POST | `/v1/sims/link/:authStateId/resend` | Resend the carrier OTP |
| GET | `/v1/sims/:id/balance` | Read the SIM balance |
| GET | `/v1/sims/:id/transactions` | List SIM transactions |
| POST | `/v1/sims/:id/share/airtime` | Share airtime |
| POST | `/v1/sims/:id/share/data` | Share data |
| POST | `/v1/sims/:id/pin` | Create, change or reset the share PIN |
| DELETE | `/v1/sims/:id` | Unlink the SIM |

Start a link with:

```bash
curl https://api.vine.ng/v1/sims/link \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"carrier":"MTN","msisdn":"08012345678","displayName":"Support line"}'
```

## Billing boundary

The plan purchase and renewal flow is dashboard-only because it debits the workspace deposit balance and requires an authenticated merchant session. SIM management can then be automated with an API key that has the `SIMS` scope.

Recurring subscription billing for a merchant's own customers is a separate product and is not part of the SIM plan API.
