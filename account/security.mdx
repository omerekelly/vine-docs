## Password

Change your password from **Settings → Security**. Changing it signs you out of every device, including the one you are using.

Use a unique password and a password manager. Vine will never ask for your password by email or chat.

## Transaction PIN

Your transaction PIN protects payouts, transfers and other money movements. Set it from the wallet if you have not created one yet. Never share it with anyone.

## Card payments

Customers enter card details on the Vine checkout. Card details are encrypted in transit and are not stored by Vine.

Never ask a customer to send card details by email, WhatsApp or any other channel.

## API keys

- Create separate keys for live and test.
- Store keys on your server, never in browser code.
- Rotate a key immediately if it is exposed.
- Delete keys you no longer use from **Dashboard → Developers**.

## Report a concern

If you notice a suspicious payment, login or message, email [support@vine.ng](mailto:support@vine.ng) immediately.
